## R（責任制約）— 決定木

各職業について次を回答（出典をメモ欄に記録）：

- Q1 業務独占資格があり **かつ 誤りが法的責任を生む** か（免許の有無だけでは不可）  … Y / N
  ※ v2 改訂: 美容師等、免許はあるが低責任の職業を R=3 と過大評価する欠陥を、第一次診断で検出したため条件を追加
- Q2 法定の署名・記名・押印・最終承認義務があるか        … Y / N
- Q3 誤りの帰結は？  … 「法的（民事・刑事・行政処分）」/「評判のみ」/「ほぼ無」
- Q4 その職業に従事する者の**業務上の判断・成果物の誤り**が、依頼者・利用者・第三者の**生命・身体の安全**、または**それに準じる重大な自由・権利の侵害**（不当な拘束・重大な冤罪・強制的な権利剥奪等）に直接関わるか … Y / N
  - **従事者本人の労働災害リスクは含めない**（作業自体の危険性ではなく、成果物・判断の誤りが引き起こす結果を問う）。
  - **財産的損害・行政手続上の不利益・金銭的トラブル**など、後から金銭賠償や手続き是正によって回復可能な損害は、それがどれほど大きくても本問ではNとする（該当する場合はQ3の「法的」評価で別途拾う）。
  - ※ 2026-07-11 改訂: 独立4コーダー（Claude系3・Codex系1、モデル系統をまたぐ評価者間信頼性検証）により、旧Q4「生命・身体・重大権利に直接関わるか」が(a)第三者被害リスクと(b)従事者本人の労災リスクの混同、および(c)「重大権利」を財産権・手続き上の不利益まで広く読むか生命身体に限定するか、という二重の解釈の余地を持つことが判明したため上記2点のただし書きを追加した。詳細は分析リポジトリの `prep/reports/07_ai_coder_kappa.md` を参照。
- Q5 EU AI Act Annex III 高リスク該当か（ロバスト性・補助） … Y / N

写像規則（上から評価し、最初に該当した点数を採用）：

- R=4 : Q4 = Y
- R=3 : Q1 = Y または Q2 = Y
- R=2 : Q3 = 法的
- R=1 : Q3 = 評判のみ
- R=0 : それ以外

注：Q5 は最終点には使わず、感度分析（Annex III を高リスク=+1 として再採点し順位安定性を確認）に用いる。

## P（価格硬直性）— 実測優先、無ければ決定木

### A. 実測（取得できれば必ずこちらを優先）

- M1 公定価格・保険点数でカバーされる売上シェア（0–100%）
- M2 同一サービス単価の変動係数 CV（横断価格分散、低い=硬直）
- M3 長期契約・顧問契約の売上比率
- M4 価格改定頻度（年あたり改定回数、低い=硬直）

実測写像（M1 を主、無ければ M2/M3）：

- P=4 : M1 > 2/3
- P=3 : 1/3 < M1 ≤ 2/3  または（M1 低でも M3 高 かつ CV 低）
- P=2 : 契約・品質差による粘着（CV 中、長期契約一部）
- P=1 : 価格比較容易・代替供給者多い（CV 高）
- P=0 : スポット市場・価格競争（CV 非常に高、改定頻繁）

### B. 決定木（実測不能時のフォールバック）

- Q1 公定価格／保険対象か  … 全面 / 部分 / 無
- Q2 資格独占による供給制限があるか … Y / N
- Q3 価格形態は？ … スポット比較容易 / 慣行・粘着 / 長期契約主体

写像：全面→4／部分 or 長期契約主体→3／慣行・粘着→2／比較容易→1／スポット→0

## 妥当性検証の手順（このコードブックを使って回す）

### ステップ 0：ゴー/ノーゴー
全職業を (B = Eloundou 曝露, R) 平面に散布。右上（高B×高R）セルの職業数を数える。
- 十分な塊（目安 ≥ 8職業）→ go
- 3–4職業のみ → 中心命題は逸話。枠組みを右上ケーススタディへ縮小再設計。

### ステップ 1：評価者間信頼性
- 30–40職業を独立コーダー 2–3 名がブラインド採点（この決定木に従う）
- R, P それぞれで Krippendorff α（順序尺度）を算出。目標 α ≥ 0.80
- 不一致は「どの Q 分岐で割れたか」を記録し、分岐定義を精緻化 → v3
- LLM コーダー panel は人手前の事前デバッグ（補助、置換不可）

### ステップ 2：外的妥当性
- R を外部代理（独占資格ダミー、保険料率、Annex III、過誤統計）に回帰 → 正の関連
- 既知群：有資格専門職 > 非資格職（t 検定 / 順位検定）
- P：実測 P（M1/M2）でコード P を置換し、本論の結果が頑健か再推定（最強の反証封じ）

### ステップ 3：因子構造
- A, B, R, P を探索的因子分析。一因子に潰れないこと（≥ 2–3 因子）を確認
- R–P の相関は中程度に留まること（別次元の証拠）
- 一因子化 → フレームワークは「AI曝露の言い換え」。設計の見直しが必要
